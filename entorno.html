Mi entorno de trabajo

Qué ocurre cuando escribo una URL

Por ejemplo, cuando escribo google.com:

  1. Escribo la dirección en el navegador y pulso Enter.
  2. El navegador pregunta a un servidor DNS cuál es la IP de google.com.
  3. Envía una petición HTTPS a esa IP.
  4. El servidor responde con un código de estado (200 si todo va bien) y el HTML.
  5. El navegador interpreta ese HTML y me muestra la página.

Herramientas que uso

  • VS Code: es el editor donde escribo el código.
  • Live Server: es una extensión que recarga la página al guardar.
  • Git: guarda el historial de cambios de mi proyecto.
  • GitHub: web que aloja mi repositorio en internet.
