Mi entorno de trabajo

Qué ocurre cuando escribo una URL

  1. Escribo la dirección en el navegador.
  2. El navegador pregunta a un servidor DNS cuál es la IP de ese dominio.
  3. Envía una petición HTTP/HTTPS al servidor.
  4. El servidor responde con un código de estado (por ejemplo 200) y el HTML.
  5. El navegador interpreta el HTML y muestra la página.

Herramientas que uso

  • VS Code: el editor donde escribo el código.
  • Live Server: extensión que recarga la página al guardar.
  • Git: guarda el historial de cambios de mi proyecto.
  • GitHub: aloja mi repositorio en internet.
